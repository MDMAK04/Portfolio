# 🚀 Personal Portfolio

A modern, responsive portfolio built with Next.js, React, and Tailwind CSS.

## ✨ Features
- **Projects Showcase**: Interactive list-to-preview layout.
- **Academic Formation**: Structured cards with progress indicators and skills.
- **Certifications**: Alternating central timeline for verified credentials.
- **Responsive Design**: Optimized for desktop, tablet, and mobile screens.

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Icons & UI**: Lucide React / Custom SVG
- **Deployment**: Vercel
